# Compliance & Security Agent — Project Showcase

An AI-assisted workspace for turning European regulatory and security requirements into practical product decisions, with source-linked research and traceable stakeholder input.

**[Explore the interactive showcase →](https://expertheidi.github.io/Compliance-Security-Agent-Showcase/)**

## Why this project

Understanding a regulation is only the beginning. Teams also need to determine what it means for their product, compare implementation options, and align input from business, product, engineering, security, DPO and Legal.

This project explores how AI can support that workflow while keeping evidence, assumptions and human decisions visible.

## Core capabilities

- **Regulatory research and interpretation**  
  Research regulations, regulatory guidance and standards in the context of a business scenario. Draft compliance and security requirements with sources, applicability conditions and open questions.

- **Product and engineering translation**  
  Translate abstract requirements into proposed product behavior, engineering tasks and acceptance criteria for review.

- **Implementation research and comparison**  
  Explore source-linked market examples and compare implementation options, highlighting constraints, unknowns and assumptions to validate.

- **Stakeholder input and decision traceability**  
  Organize role-specific opinions around shared requirements and preserve decision context and revision history.

The local application also supports scenario import/export and case-package migration.

## What this repository contains

This repository contains the static project showcase and an illustrative interactive demo.

- `index.html` — page structure
- `style.css` — visual styling
- `app.js` — demo interactions

The full Python application is maintained in a separate private repository. The public demo uses fictional content and does not run the Agent's live research or analysis backend.

## Current scope

The Agent is a local prototype under active development. In the current personal-use version, stakeholder opinions are entered by the user; it is not a live multi-user collaboration platform.

AI-generated requirements and implementation options are drafts for review. Market examples inform design and do not establish compliance. Professional judgment remains with the relevant stakeholders.
